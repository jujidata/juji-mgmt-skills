# 项目进度展示流程

## 目标

用于跟踪项目执行状态，并根据实际进度输出简洁的汇报内容。

## 典型步骤

1. 获取项目基础信息，包括名称、负责人、截止日期和当前阶段。
2. 收集各项任务的完成状态、待办项和风险事项。
3. 对任务状态做分类：已完成、进行中、延期、阻塞。
4. 计算完成率和关键里程碑达成情况。
5. 汇总成中文进度说明，并展示图表或简报。

## 输出建议

- 项目总览：当前阶段、完成进度、风险说明。
- 关键事项：本周完成、下一步计划、需要协作的点。
- 数据展示：使用脚本输出柱状图、折线图或进度仪表盘。

## 适用场景

适用于项目管理、客户实施、运营推进和内部协同场景。
