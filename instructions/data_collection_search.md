# 数据收集项目检索流程

## 目标

用于在已采集的数据集中快速查找目标记录，并支持筛选、统计和汇报。

## 典型步骤

1. 明确检索维度，例如企业、时间范围、地区、状态或标签。
2. 读取数据集合中的关键字段，并做去重和基本清洗。
3. 在目标范围内进行条件过滤，定位符合要求的样本。
4. 汇总统计结果，如数量、占比、异常值和趋势变化。
5. 若需要，可调用脚本生成图表和可视化摘要。

## 建议方式

- 优先使用清晰的分组字段，减少无效检索。
- 对结果做必要的解释，避免只返回原始数据。
- 结合业务语境给出结论，例如“高价值客户群体集中在北区”。

## 适用场景

适合客户资料收集、市场调研、运营分析和数据管理项目。
