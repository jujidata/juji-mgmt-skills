# 人脸去重额度

## 各采集项目的累计用量

1. 使用 `list_projects` 按 `project_type=collection` 查询当前 Key 有权查看的采集项目。沿用 [项目列表](project_progress.md#项目列表) 的分页规则，按项目 ID 去重。
2. 对每个项目调用 `get_project_statistics`，取 `used_dedup_face_quota`。一条记录对应一次已扣减的去重额度，计入软删除任务和命中重复的扣费任务。统计基于仍可追溯的扣费记录，硬删除的记录可能无法计入。
3. 按项目名称和 ID 展示累计已用次数。有效的 `0` 表示没有可追溯的扣费。字段缺失、为 `null` 或请求失败时，标为“用量不可用”。分页未完成或部分项目查询失败时，说明结果覆盖范围；若展示合计，注明“已查到的项目小计”。

## 企业共享额度

使用 `get_enterprise_face_dedup_quota` 查询 API Key 绑定企业的额度。用户只问企业余额时，直接调用该工具。

| 字段 | 展示 |
| --- | --- |
| `total_dedup_face_quota` | 企业总额度 |
| `used_dedup_face_quota` | 企业已用额度 |
| `remaining_dedup_face_quota` | 企业剩余额度 |

余额以企业接口的返回值为准。因为项目列表受访问权限限制，且项目统计依赖保留的扣费记录，已查到的项目小计可能与企业已用额度不同。余额为负时按实际值说明超额次数。

企业额度接口返回 404 或项目统计缺少用量字段时，说明对应环境暂未提供该能力，分别报告仍可获得的结果。任务总量、提交量和查重命中数不能替代扣费次数。
