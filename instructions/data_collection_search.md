# 数据采集相关查询边界

## 当前状态

PR !1319 和 PR !1322 提供的是 API Key 认证及第一批企业、项目只读接口。当前开放 API **尚未提供**：

- 采集记录或任务明细列表。
- 按姓名、地区、标签、时间或状态搜索采集数据。
- 原始人脸图片、标注结果或人员信息。
- 数据导出、创建、更新、弃用或查重操作。

因此不得使用参考框架中的记录搜索、记录汇总或任务列表占位接口；它们不属于当前开放 API 契约。

## 可提供的替代信息

当用户询问数据采集进展时，可以：

1. 查询有权访问的项目并确认目标项目。
2. 调用项目统计接口获取任务总数、完成数、待审核数、已有标注任务数和跳过数。
3. 明确说明结果是项目级聚合统计，不包含具体采集记录。

当用户明确需要记录级搜索或导出时，应说明当前 Skill 不支持，并建议等待相应开放 API 上线；不要尝试调用内部 JWT 接口或构造未声明的请求。
